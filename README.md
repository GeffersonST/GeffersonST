### 🔍 Featured work: OrgAudit360

An AI-powered Salesforce auditing platform, live with paying customers and funded by Portugal's PRR and the European Union. I was the **sole frontend owner**, working alongside one backend developer.

- **Scale:** 57 screens, 105 custom components, ~70,000 lines of TypeScript/React (87% of the repository)
- **Architecture:** multi-tenant (SMB, Enterprise multi-org and backoffice), with plan-based feature gating resolved in Next.js middleware at the edge
- **Auth:** hand-rolled OAuth 2.0 + PKCE (RFC 7636) on the Web Crypto API, migrated from implicit flow with zero downtime
- **Payments:** end-to-end Stripe integration (checkout, invoice preview, upgrades/downgrades)
- **Data viz:** Recharts dashboards, a geographic risk heat map (Leaflet + D3), custom SVG gauges and client-side PDF reports
- **Product thinking:** two role-based dashboards over the same data: remediation guides for developers, risk score and revenue impact for executives
- **Quality:** i18n across ~4,900 strings and ARIA accessibility in 69 components

🔗 [orgaudit360.ai](https://orgaudit360.ai) · *Source code is proprietary.*
